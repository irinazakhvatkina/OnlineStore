# 🛍️ Online Store — Swift UIKit Project

Мобильное приложение Online Store — учебный проект, созданный тремя разработчиками на языке Swift (UIKit).  
Приложение реализует базовый функционал интернет-магазина с разделением ролей пользователей: Client и Manager.

---

## 📱 Основная идея
Online Store позволяет пользователям просматривать каталог товаров, добавлять их в избранное и корзину, искать по названию, а также управлять своим профилем.  
При смене роли на *Manager* появляется дополнительная вкладка для управления товарами (добавление, редактирование).

---

## ⚙️ Технологии и стек

- Язык: Swift 
- Фреймворк: UIKit  
- Архитектура: MVVM  
- UI: SnapKit (автолэйауты в коде)  
- Сетевой слой: API для товаров - https://fakeapi.platzi.com/en/rest/products/, API для валюты - https://openexchangerates.org/account/app-ids/?yep=app_id_updated
- Локальное хранилище: UserDefaults / Core Data  
- Интерфейс навигации: UITabBarController, UINavigationController

---

## 🧭 Структура приложения

| Вкладка | Назначение | Доступ |
|----------|-------------|--------|
| 🏠 Home | Каталог товаров | Все пользователи |
| ❤️ Wishlist | Избранное | Все пользователи |
| 🔍 Search | Поиск по каталогу | Все пользователи |
| 👤 Account | Профиль и смена роли | Все пользователи |
| 🧑‍💼 Manager | Управление товарами | Только менеджеры |
| 🛒 Cart | Корзина с добавленными товарами | Все пользователи |

---

## 🧩 Основной функционал

- Просмотр списка товаров с изображениями, описанием и ценой  
- Экран деталей товара с кнопкой *Добавить в корзину*  
- Добавление и удаление товаров из Wishlist  
- Поиск товаров в режиме реального времени  
- Смена типа аккаунта (*Client ↔ Manager*)  
- Динамическое обновление вкладок при смене роли  
- Manager-панель: добавление, редактирование товаров  
- Хранение данных о корзине и избранном локально
